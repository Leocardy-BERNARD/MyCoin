# MyCoin Blockchain

MyCoin est un projet de blockchain simplifiée développé en Python avec Flask.

## Fonctionnalités

- Création d'une blockchain
- Génération automatique des blocs
- Transactions entre utilisateurs
- Gestion des wallets
- Vérification du solde avant transaction
- Interface web avec Flask
- Affichage des hashes SHA-256

## Technologies utilisées

- Python
- Flask
- HTML
- CSS
- SHA-256 (hashlib)
